# 产品设计文档 —— DeepSeek Harness 桌面版「沉浸式窗口」迭代

- 版本：v1.0（待确认）
- 日期：2026-08-18
- 状态：**已确认并实施，待桌面验收**
- 前置背景：桌面壳（`dsh-desktop`）已交付，当前为 macOS 标准标题栏窗口 + Electron 默认图标。本轮为视觉/交互迭代。

---

## 1. 需求背景与目标

| 项目 | 说明 |
|---|---|
| 背景 | 桌面应用已可运行（后端 + GUI + git 升级闭环），但视觉上仍是"套了壳的浏览器"，缺乏桌面应用质感 |
| 目标 1 | 应用图标替换为 **DeepSeek 品牌图标**（Dock、About、任务切换等场景） |
| 目标 2 | **取消顶部标题栏**，页面沉浸式铺满窗口（frameless） |
| 目标 3 | 窗口左上角操控区（关闭/最小化/最大化）**默认显示纯色圈圈，鼠标移入后显示实际操作图标**（✕/−/＋） |
| 非目标 | 不改 harness 前端源码（壳层注入实现）；不做 Windows/Linux；不做托盘 |

## 2. 用户故事

1. 作为用户，我打开应用时看到的是 DeepSeek 图标，而不是 Electron 默认图标。
2. 作为用户，我希望窗口没有标题栏/菜单栏遮挡，页面内容延伸到顶部，更沉浸。
3. 作为用户，我扫一眼左上角就知道"这里是三个窗口按钮"（圈圈），鼠标移上去才出现具体的关闭/最小化/最大化符号，视觉干净。
4. 作为用户，我依然可以拖动窗口、双击顶部还原/最大化、用快捷键 ⌘W/⌘M 等原生方式操作窗口。

## 3. 功能需求

### FR-1 应用图标（DeepSeek 品牌）

- **范围**：应用 bundle 图标（Dock/Launchpad/About/⌘Tab）。
- **图标来源**（二选一，需用户确认）：
  - A. 用户提供 DeepSeek 官方图标文件（png/svg/icns）
  - B. 从 DeepSeek 官网/官方公开渠道获取官方 logo（PNG/SVG）后加工为 1024×1024 图标
- **加工**：1024×1024 PNG（圆角/留白符合 macOS 图标规范）→ 构建时生成 `.icns`。
- **兜底**：若来源不可用，保持默认图标并在文档标注。

### FR-2 沉浸式窗口（frameless）

- 窗口**无标题栏、无边框**，`BrowserWindow` 使用无边框模式。
- 页面内容（GUI）铺满整个窗口，顶部不再有系统标题栏。
- 保留：窗口阴影、四角圆角（macOS 系统渲染）、缩放/全屏能力。
- 顶部预留**拖拽区**（约 32px），支持拖动窗口、双击最大化/还原。

### FR-3 窗口操控区（红绿灯）

- 采用**系统原生红绿灯**（`titleBarStyle: 'hidden'`）：左上角红黄绿三灯由 macOS 系统渲染，**默认显示为灰圈，鼠标移入显示 ✕/−/＋ 符号**（原生行为，无需自绘）。
- 位置可通过 `trafficLightPosition` 微调（垂直居中对齐 32px 拖拽区）。
- 全屏时系统自动隐藏红绿灯（原生行为）。
- 交互均为原生：关闭/最小化/最大化/还原、⌘W/⌘M、空格键触发。
- 窗口拖动：顶部 32px 整条由壳层注入的拖拽区（`-webkit-app-region: drag`）承担；双击拖拽区最大化/还原（壳层处理）。

### FR-4 兼容既有功能

- 菜单（检查更新/重启后端/关于等）不变；快捷键 ⌘U 等不变。
- 升级进度窗口保持普通有边框窗口（避免进度页也沉浸化的复杂度）。
- 后端、数据目录、升级机制全部不受影响。

## 4. 交互与视觉规格

| 项 | 规格 |
|---|---|
| 红绿灯 | 系统原生（`titleBarStyle: 'hidden'`），macOS 红黄绿，默认灰圈 / hover 出符号 |
| 红绿灯位置 | `trafficLightPosition` 微调，垂直居中于 32px 拖拽区（约 x=16, y=14） |
| 拖拽区 | 顶部 32px 整条，`-webkit-app-region: drag`（壳层注入，不影响页面源码） |
| 双击拖拽区 | 最大化/还原（壳层 IPC 处理） |
| 全屏 | 红绿灯系统隐藏；拖拽区同步隐藏（壳层监听全屏事件） |
| 注入方式 | 壳层 preload 注入（不动 harness 前端源码） |
| 深色/浅色 | 红绿灯由系统渲染，自动适配 |

## 5. 验收标准

1. 打包后的 `.app` 图标为 DeepSeek 图标（Dock 可见）。
2. 窗口无标题栏，页面内容铺满，可正常拖动、双击最大化/还原、缩放、全屏。
3. 左上角为 macOS 原生红绿灯：默认圆圈，鼠标移入显示 ✕/−/＋，点击行为正确（关闭退出、最小化、最大化/还原）。
4. 全屏时红绿灯与拖拽区隐藏，退出全屏恢复。
5. 既有的检查更新/重启后端/关于/升级进度窗口功能回归通过。
6. 冒烟测试（`scripts/smoke.sh`）通过；无孤儿后端进程。
7. 页面顶部原有可交互内容未被拖拽区遮挡（或按风险对策调整后不遮挡关键功能）。

## 6. 决策记录（已确认 2026-08-18）

| 决策点 | 结论 |
|---|---|
| 图标来源 | **我下载 DeepSeek 官方图标**并加工（1024×1024 PNG → icns） |
| 红绿灯实现 | **系统原生红绿灯**（`titleBarStyle: hidden` + `trafficLightPosition`） |
| 配色 | macOS 原生红黄绿（系统渲染，自动适配深浅色） |
| 拖拽区 | 整条 32px（双击最大化/还原；若发现遮挡再收窄） |
