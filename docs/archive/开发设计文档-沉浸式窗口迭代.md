## 1. 设计原则

1. **壳层注入，零前端改动**：harness 前端（React SPA）源码一行不改。沉浸式所需的拖拽区由 Electron 壳注入——preload 在页面上下文中创建 DOM 节点，样式与逻辑封装在壳内。若未来 harness 前端结构调整，壳层独立适配。
2. **红绿灯用系统原生**：`titleBarStyle: 'hidden'` 保留 macOS 原生红绿灯（默认灰圈 → hover 出符号、全屏自动隐藏均为系统行为），壳层只负责：调整红绿灯位置、注入拖拽区、处理双击最大化。
3. **保持既有闭环不回归**：后端 spawn/就绪解析、git 升级、进度窗口、优雅退出逻辑不动；改动集中在窗口创建与 preload。
4. **状态单一来源**：窗口状态（最大化/全屏）由主进程持有，通过 IPC 推送给渲染层，渲染层只反映状态。

## 2. 总体架构（改动后）

```
Electron 主进程 (src/main.ts)
 ├─ createMainWindow: titleBarStyle:'hidden' + trafficLightPosition + 新 IPC + 状态事件推送
 ├─ 后端 spawn / 升级 / 菜单 / 退出：不变
 └─ BrowserWindow(loadURL http://127.0.0.1:port)
      └─ preload (src/preload.ts)
           ├─ 既有 contextBridge API（版本/更新/日志）：不变
           └─ 新增 injectDragRegion()
                ├─ <div id="dsh-drag-region">（顶部 32px 拖拽条）
                └─ dblclick → ipcRenderer.send('dsh:window-control','toggle-maximize')
                   ← ipcRenderer.on('dsh:window-state', 全屏时隐藏拖拽区)
```

## 3. 窗口配置（src/main.ts 修改点）

```ts
new BrowserWindow({
  titleBarStyle: 'hidden',          // macOS: 隐藏标题栏，保留原生红绿灯
  trafficLightPosition: { x: 16, y: 14 }, // 微调红绿灯位置（垂直居中于 32px 拖拽区）
  // 保留：width/height/webPreferences/preload/contextIsolation/sandbox 不变
})
```

- 不采用 `frame:false`/`transparent:true`：`titleBarStyle:'hidden'` 保留原生红绿灯与系统窗口行为（阴影、圆角、全屏、缩放），规避自绘控件与透明窗口的合成问题。
- 全屏、缩放（zoom）、⌘M/⌘W 等原生能力不受影响。

## 4. 拖拽区注入（src/preload.ts 新增）

### 4.1 注入时机

- `document.readyState === 'loading'` 时监听 `DOMContentLoaded`，否则立即注入；页面为 SPA，注入节点挂在 `<body>` 顶层，React 只管理自己的 root，不冲突。
- 幂等：以 `#dsh-drag-region` 是否存在判断，避免重复注入（HMR/重载场景）。

### 4.2 DOM 结构

```html
<div id="dsh-drag-region"></div>
<!-- fixed 顶部整条 32px; -webkit-app-region: drag; 全屏时隐藏 -->
```

- 样式写入 `<style id="dsh-wc-style">`：`position:fixed; top:0; left:0; right:0; height:32px; -webkit-app-region:drag; z-index: 2147483000;`（红绿灯为系统原生控件，渲染在内容之上，不受拖拽区影响）。
- 全屏态：主进程推送 `fullscreen:true` → 拖拽区 `display:none`（避免顶部条在全屏下遮挡内容/误触）。

### 4.3 事件

| 事件 | 处理 |
|---|---|
| 拖拽区 dblclick | `ipcRenderer.send('dsh:window-control', 'toggle-maximize')` |
| 拖拽区 mousedown 拖动 | 由 `-webkit-app-region: drag` 系统处理 |
| 红绿灯点击 | 系统原生，壳层不介入 |

## 5. 主进程 IPC（src/main.ts 新增）

```ts
ipcMain.on('dsh:window-control', (event, action) => {
  // 安全：仅接受主窗口 webContents
  if (event.sender !== mainWindow?.webContents) return
  if (action === 'toggle-maximize') {
    mainWindow.isMaximized() ? mainWindow.unmaximize() : mainWindow.maximize()
  }
})
```

状态推送（全屏时隐藏拖拽区）：

```ts
const pushWindowState = () => mainWindow?.webContents.send('dsh:window-state', {
  maximized: mainWindow.isMaximized(),
  fullscreen: mainWindow.isFullScreen(),
})
mainWindow.on('maximize', pushWindowState)
mainWindow.on('unmaximize', pushWindowState)
mainWindow.on('enter-full-screen', pushWindowState)
mainWindow.on('leave-full-screen', pushWindowState)
```

## 8. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| SPA 结构变化导致注入节点被清掉 | 拖拽区消失 | 注入幂等 + 每次 `loadURL`/`did-navigate` 后重新注入；挂 `MutationObserver` 兜底 |
| 拖拽区遮挡页面顶部可交互元素 | 页面顶部按钮点不到 | 拖拽区高度 32px；若 GUI 顶部存在高频控件，收窄拖拽区到左右两侧空白或加 `no-drag` 白名单（决策记录中已约定"发现遮挡再收窄"） |
| 原生红绿灯与拖拽区叠放 | 红绿灯不可点/位置错 | 红绿灯为系统控件渲染在内容之上，验证点击与拖动互不干扰；`trafficLightPosition` 微调位置 |
| `titleBarStyle:'hidden'` 下拖拽区双击行为 | 双击不最大化 | 壳层监听 dblclick → IPC toggle-maximize |
| 注入样式污染 GUI | 视觉错乱 | 所有样式带 `#dsh-` 前缀 + 固定定位 + 极高 z-index |
| 升级/进度窗口误加沉浸化 | 复杂度上升 | 进度窗口保持普通边框窗口，不注入拖拽区 |
